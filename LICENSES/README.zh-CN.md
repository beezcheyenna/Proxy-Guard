# 许可原文与上游副本

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [فارسی](README.fa.md)

根目录 [LICENSE](../LICENSE) 为 Proxy Guard 自有代码的 MIT 许可。本目录对应[第三方声明](../docs/THIRD_PARTY_NOTICES.zh-CN.md)和[组件清单](../docs/THIRD_PARTY_COMPONENTS.json)，各组件仍适用其原版权、NOTICE、文件级例外和源码义务。

`UPSTREAM/` 保存上游许可与通知，[SOURCES.json](SOURCES.json) 记录 URL 和 SHA256。许可文件的哈希只对应文件本身。`GPL-2.0-only.txt`、`GPL-3.0-only.txt` 保存相应文本，组件能否选用更高版本以原始授权为准。

LGPL-3.0-or-later、0BSD、CC0 等是 Worker 开发依赖的参考文本。分发实际依赖时保留其完整声明及源码。普通版和 Pro 各自安装适用的许可文件。公开源码在此提供共有参考文本，兼容的普通版可以继续与 Pro 配合。
