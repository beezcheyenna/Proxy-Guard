The root LICENSE is the MIT license for original Proxy Guard code.

The texts in this directory are supplied for the components identified in the [third-party notices](../docs/THIRD_PARTY_NOTICES.md) and [component inventory](../docs/THIRD_PARTY_COMPONENTS.json). They do not collectively relicense the application. SPDX reference texts are not substitutes for an actual component's copyright, NOTICE, file-level exceptions or source obligations.

UPSTREAM/ preserves license documents and notices retrieved from the listed upstreams. SOURCES.json records the exact URLs and SHA256 values. A license-file hash does not attest to the bytes of an upstream binary or the version installed on a device.

GPL-2.0-only.txt and GPL-3.0-only.txt contain the respective license texts. Whether a component permits later versions is determined by its original grant; this filename does not change a GPL-3.0-or-later grant.

The LGPL-3.0-or-later, 0BSD, CC0 and other development-tool texts are reference copies for the Worker lockfile inventory. No npm dependencies or native tools are vendored by this supplement. If such code is distributed later, retain its complete actual notices and corresponding source requirements.

The installed LuCI base package contains the license subset relevant to its application/message material. Pro keeps its own MIT, licensing summary and notices in a separate directory. This source distribution supplies the shared reference texts here; the notices do not require a base-package upgrade beyond the declared API compatibility.
