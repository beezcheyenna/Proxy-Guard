# Тексты лицензий и копии источников

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [فارسی](README.fa.md)

Корневой [LICENSE](../LICENSE) содержит MIT для оригинального кода. Каталог соответствует [сторонним уведомлениям](../docs/THIRD_PARTY_NOTICES.ru.md) и [списку компонентов](../docs/THIRD_PARTY_COMPONENTS.json). Авторство, NOTICE, исключения файлов и требования исходников берутся из условий компонента.

`UPSTREAM/` хранит исходные уведомления и лицензии, [SOURCES.json](SOURCES.json) содержит URL и SHA256. Сумма относится к самому файлу лицензии. `GPL-2.0-only.txt` и `GPL-3.0-only.txt` содержат соответствующие тексты. Возможность поздней версии определяет исходное разрешение.

LGPL-3.0-or-later, 0BSD, CC0 и другие тексты справочны для инструментов Worker. При распространении зависимостей сохраняйте полные уведомления и требуемые исходники. Standard и Pro устанавливают свои файлы. Общие оригиналы хранятся здесь, совместимая база продолжает работать с Pro.
