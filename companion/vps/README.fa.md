مؤلفهٔ VPS برای Pro و پورت‌های محلی منتخب است. مجوز احراز هویت‌شدهٔ IP خانه، سیاست هر پورت، نجات اختیاری SSH و نگهداری صریح دارد. استاندارد به آن نیاز ندارد.

- [معماری و رفتار خرابی](../../docs/PRO-COMPANION.fa.md)
- [سازگاری مؤلفه‌ها](../../docs/EDITION-MATRIX.fa.md)
- [سیستم‌های آزموده و محدودیت](../../docs/TEST-MATRIX.fa.md)
- [بازیابی بدون LuCI](../../docs/RECOVERY.fa.md)

Python 3.10 یا بالاتر، nftables و systemd یا OpenRC لازم‌اند. HTTPS مستقیم یا Cloudflare را انتخاب کنید. هسته و 3x-ui جدا نصب می‌شوند. پیش از فعال‌سازی مسیر مدیریت را نگه دارید. پورت انتخاب‌نشده تابع فایروال قبلی است.
