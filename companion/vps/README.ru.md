# Proxy Guard VPS Agent

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [فارسی](README.fa.md)

Компонент Pro для выбранных локальных портов VPS. Предоставляет аутентифицированные домашние разрешения, правила портов, необязательный аварийный SSH и явно разрешённое обслуживание. Standard работает без него.

- [Установка, обновление и удаление](../../docs/LINUX-AGENT-INSTALL.ru.md)
- [Архитектура и сбои](../../docs/PRO-COMPANION.ru.md)
- [Совместимость компонентов](../../docs/EDITION-MATRIX.ru.md)
- [Проверенные системы и ограничения](../../docs/TEST-MATRIX.ru.md)
- [Восстановление без LuCI](../../docs/RECOVERY.ru.md)

Нужны Python 3.10+, nftables и systemd или OpenRC. Выберите прямой HTTPS или Cloudflare. Ядро прокси и 3x-ui устанавливаются отдельно. Сохраните управление перед включением. Невыбранные порты подчиняются существующему экрану.
