رلهٔ اختیاری کنترل Pro میان OpenWrt و VPS Agent از طریق Tunnel/VPC Service است. احراز هویت، سیاست و وضعیت را عبور می‌دهد. دادهٔ پروکسی و ضربان مستقل SOCKS مسیر جدا دارند.

- [نصب VPS Agent](../../docs/LINUX-AGENT-INSTALL.fa.md)

نسخهٔ npm برابر 0.2.0 و پروتکل Agent v3 است. منبع یک انتشار را به‌کار ببرید و اتصال، رمز جدا و پاسخ واقعی را بسنجید. آزمون محلی و ابری جداست. HTTPS مستقیم Worker نمی‌خواهد.
