# Сравнение Standard и Pro

[English](EDITION-MATRIX.en.md) · [简体中文](EDITION-MATRIX.md) · [日本語](EDITION-MATRIX.ja.md) · [Русский](EDITION-MATRIX.ru.md) · [فارسی](EDITION-MATRIX.fa.md)

Standard `0.3.0-21` защищает соединения на роутере. Pro `0.3.1-5` добавляет управление доступом к выбранным портам VPS. Пакеты и ревизии независимы.

| Область | Standard | Pro |
| --- | --- | --- |
| Развёртывание | Маршрутизатор OpenWrt | Расширение и отдельный Linux Agent, Worker/Tunnel по выбору |
| Проверки прокси | HTTPS через SOCKS, необязательные IPv4-выход и SOCKS5 UDP | Проверки Standard и импорт кандидатов выхода VPS |
| Локальные правила | Выбранный вход, диапазоны, исключения, IPv4/IPv6 TCP/UDP | Использует Standard |
| Клиенты | PassWall, PassWall2, OpenClash, Nikki, HomeProxy в проверенных версиях и режимах | Использует Standard |
| Защита | Пороги, ожидание, усиленное наблюдение, запуск и расписание | Необязательное условие удалённого здоровья и восстановление после обслуживания |
| Интерфейс | Статус, журналы событий и проверок, пять языков, мастер, UCI, самопроверка и ограниченное восстановление | Порты, аутентифицированная связь, удалённый статус и фиксированные операции |
| Порты VPS | — | Список допуска, ограничение ресурсов или наблюдение по правилу, источники и пороги |
| SSH | — | Отдельное включение, постоянный или временный аварийный доступ после потери двух сигналов |
| Обслуживание | — | Отдельно разрешаемые перезагрузка VPS и перезапуск поддерживаемого Xray, в том числе через адаптер 3x-ui |

## Раздельное обновление

Pro проверяет минимальную версию Standard и базовый API. При совместимости можно обновить только Pro. Для исправлений защиты, безопасности и прошивки обновляется Standard. У Pro свои страницы на пяти языках, подтверждение политики и редактор UCI.

Если сначала обновить Standard, его обработчик сохранит старые строки, необходимые установленному Pro. Новый Pro удалит временный каталог. Возможности Agent и Worker проверяются отдельно. Для новых функций могут потребоваться обновления обоих.

## Текущая область

При новой установке Standard и Pro выключены. SSH и обслуживание разрешаются отдельно. Обнаружение предлагает порты, невыбранными управляет системный экран. По умолчанию управление и синхронизация домашнего IP используют IPv4. Покрытие данных IPv6 проверяется отдельно.

Развёртывание рассчитано на один идентификатор роутера и Agent. Проверяйте свою схему и клиент. Точная классификация fallback требует доверенных структурированных данных. После проверки процесса, порта и журнала запуска проверьте реальные запросы прокси. См. [совместимость](COMPATIBILITY.ru.md).

## Минимальная совместимость выпуска

| Компонент | Выпуск или идентификатор | Требование |
| --- | --- | --- |
| Standard IPK | 0.3.0-21 | LuCI, opkg, firewall4/nftables и подходящие зависимости |
| Pro IPK | 0.3.1-5 | Standard **≥ 0.3.0-13**, базовый **API 1** |
| Standard APK | 0.3.0-r21 | Подходящий SDK, apk, LuCI, firewall4/nftables |
| Pro APK | 0.3.1-r5 | Standard **≥ 0.3.0-r20**, базовый **API 1** |
| VPS Agent | **v3** | Проверяются протокол, возможности и подтверждение политики |
| Проект npm Worker | **0.2.0** | Пересылает и проверяет ответы v3. Версия npm относится к инструментарию |

Зависимости и константы API заданы в [package/Makefile](../package/Makefile). IPK и APK имеют свой формат ревизий. Минимум — порог установки. Возьмите Agent и при необходимости Worker из [исходников соответствующего выпуска (на английском)](https://github.com/beezcheyenna/Proxy-Guard/releases/tag/v0.3.0-21-pro-0.3.1-5) и запишите тег или коммит. Проверяйте фактически развёрнутый Worker отдельно от версии в `package.json`.

### Выбор компонентов для обновления

| Изменение | Действие | При несовместимости |
| --- | --- | --- |
| Интерфейс Pro, перевод или исправление для API 1 | Обновить только Pro с совместимой базой | Несовместимая база отклоняется при установке или запуске |
| Исправление Standard при API 1 | Обновить только Standard | Новые основные API проверять отдельно |
| Правила портов, источники или пробное применение | Сначала обновить Agent, при Cloudflare также Worker и проверить их | Без `per_rule_modes`, `source_modes_v2` или `policy_confirmation` применение отклоняется |
| Протокол или ответ ретранслятора не совпадают | Использовать совместимые исходники и сквозную проверку. Прямой HTTPS идёт к Agent | Ошибка, проверить действующие правила |
| Импорт адреса VPS | Поддержка схемы 1 в Agent и на пути управления | Неподдерживаемые и неверные кандидаты отклоняются, проверки Standard продолжаются |

Для Pro сохраните совместимый Standard. При ошибке применения прежние правила могут остаться. Сверьте ревизию, подтверждение и живые правила по [руководству восстановления](RECOVERY.ru.md).
