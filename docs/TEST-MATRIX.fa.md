ترکیب‌های واقعاً آزموده‌شده ثبت شده‌اند. انتشار فعلی استاندارد `0.3.0-21` و Pro `0.3.1-5` است. [سازگاری](COMPATIBILITY.fa.md) و [مقایسهٔ نسخه‌ها](EDITION-MATRIX.fa.md) را ببینید.

## خواندن نتیجه‌ها

- **شبیه‌سازی و آزمون واحد** ساعت، رابط یا فراخوان سیستم را برای سنجش تجزیه و تغییر وضعیت جایگزین می‌کند.
- **یکپارچگی ماشین مجازی ایزوله** هسته، init، مدیر بسته و پروکسی واقعی مهمان را با همتای کنترل‌شده می‌آزماید. قبولی محدود به مورد ذکرشده است.
- **پذیرش استقرار** دستگاه واقعی، کارت شبکه، سوئیچ، خط ارائه‌دهنده، برگشت نامتقارن و بار طولانی را دربر می‌گیرد.
- **یکپارچگی ابری** احراز هویت و کنترل Worker/Tunnel واقعی را می‌سنجد. مسیر داده و راه‌اندازی سرد جدا بررسی می‌شوند.

تاریخ‌ها UTC هستند. تاریخ قدیمی لینوکس، زمان ذخیرهٔ نتیجه است. نصب، شروع فرایند یا بازشدن صفحه به‌تنهایی تأیید عملکرد نیست.

## Linux VPS Agent

آزمون‌های پیشین ماشین مجازی ایزولهٔ `x86_64` با مدیریت سرویس بومی و nftables.

| توزیع | هستهٔ مهمان | init | مورد | نتیجهٔ ذخیره‌شده |
| --- | --- | --- | --- | --- |
| Ubuntu 24.04.5 LTS | 6.8.0-147-generic | systemd | A / B / C | موفق, 2026-11-02 |
| Debian 13.7 | 6.12.113+deb13-amd64 | systemd | A / B / C | موفق, 2026-11-02 |
| Rocky Linux 10.2 | 6.12.0-211.16.1.el10_2.0.1.x86_64 | systemd | A / B / C | موفق, 2026-11-02 |
| Alpine Linux 3.23.7 | 6.18.58-0-virt | OpenRC | A / B / C | موفق, 2026-11-02 |

- **A — نصب و سیاست:** نصب بومی و نصب مجدد همان نسخه، حفظ تنظیم و مجوز، API احراز هویت، سه حالت پورت، IPv4/IPv6 TCP/UDP و حفظ قانون‌های دیگر.
- **B — پروکسی و نگهداری واقعی:** 3x-ui **3.11.0** و **Xray 26.10.21** برای VLESS، شنونده، راه‌اندازی مجاز هسته و بازیابی بررسی شدند. SHA256 فایل ماشین مجازی نگه‌داری‌شده با بایگانی بررسی‌شدهٔ 3x-ui یکسان بود.
- **C — چرخهٔ عمر:** شروع پس از راه‌اندازی مجاز، بازگشت سیاست آزمایشی، حذف تکرار، حذف و نصب دوباره، حفظ 3x-ui و قانون‌های دیگر.

SHA256 ثبت‌شدهٔ `agent.py` برابر `3896c1c2d528aab70a9e071ab7c23a18831bfe5f111d906da5925e1af4689d90` و پروتکل v3 است. Agent و Worker را از منبع انتشار سازگار بگیرید و قابلیت تازه را بسنجید. Agent پورت محلی منتخب INPUT را مدیریت می‌کند. نگاشت Docker، فضای نام دیگر، گروه امنیتی بالادست و سیستم فهرست‌نشده پوشش داده نشده‌اند.

## ابر و محیط عملیاتی

آزمون زندهٔ پیشین Cloudflare احراز هویت، سیاست و قطع Tunnel را پوشش داد. آزمون بازیابی ایزوله بود. برای قبولی ابری بازبینی استقرار و گزارش کامل لازم است. نسخهٔ npm Worker به‌تنهایی استقرار را مشخص نمی‌کند. روی دستگاه واقعی با یک کلاینت، مسیر رفت و برگشت، شتاب‌دهی و شروع را بسنجید. برای محافظت راه‌اندازی، روتر دارای Proxy Guard را دوباره راه‌اندازی کنید. [نصب و استفاده](USAGE.fa.md) را ببینید.
