# جدول آزمون‌های سازگاری

[English](TEST-MATRIX.en.md) · [简体中文](TEST-MATRIX.md) · [日本語](TEST-MATRIX.ja.md) · [Русский](TEST-MATRIX.ru.md) · [فارسی](TEST-MATRIX.fa.md)

موارد زیر با Proxy Guard 1.0.0-r7 روی x86_64 بررسی شده‌اند. در ماشین‌های مجازی ایزوله از LuCI، SOCKS، TLS و nftables واقعی و سرویس‌های آزمایشی محلی برای HTTPS استفاده شد.
