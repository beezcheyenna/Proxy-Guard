# 兼容性测试矩阵

本页记录**实际验证过的组合**，不把“支持某系列”当作所有版本、架构或拓扑均已通过。当前发布为普通版 `0.3.0-21`、Pro `0.3.1-5`。安装条件与限制见[兼容说明](COMPATIBILITY.md)，组件升级条件见[版本与接口](EDITION-MATRIX.md)。

## 如何阅读结果

- **模拟／单元测试**：替换时钟、接口或系统调用，用于验证解析和状态机；不能证明真实包安装或数据包阻断。
- **隔离 VM 集成测试**：启动发行版自己的内核、init、包管理器及实际代理程序，在受控对端间验证流量。表中的“通过”均限定于所列项目。
- **真实部署验收**：实际设备、物理网卡、交换芯片、运营商链路、非对称回程和长时间负载。本页不宣称已完成所有用户环境的这一层验收。
- **云端联调**：真实 Worker / Tunnel 的认证与控制链路检查，单独列示；不能替代代理数据通路或路由器冷启动验收。

日期使用 UTC。历史 Linux 记录的日期按结果文件保存日期列出，未保留的字段明确标为“未留存”。一次下载、进程启动、软件包已安装或页面能打开，均不单独计为功能通过。

- **A — 安装与策略：** 原生安装、同版本重装、配置及权限保留、认证 API、三种端口模式、IPv4/IPv6 TCP/UDP 和非托管规则保留。
- **B — 实际代理与维护：** 3x-ui **3.11.0** 与配套 **Xray 26.10.21** 创建 VLESS 入站并实际通流；核验监听、授权内核重启和恢复。Xray 版本在本次留存 VM 中补读，并通过二进制 SHA256 与该轮已校验的 3x-ui 官方归档核对一致；不是把后续路由器上的 Xray 26.11.9 套用到 Linux 结果。
- **C — 生命周期：** 授权重启后的启动与状态恢复、待确认策略回退、操作去重、实际卸载与重装、保留 3x-ui 运行及其他防火墙规则。

该轮记录中的 Agent `agent.py` SHA256 为 `3896c1c2d528aab70a9e071ab7c23a18831bfe5f111d906da5925e1af4689d90`，控制协议为 v3。单个文件哈希不证明整个配套目录完全相同；应按[组件兼容表](EDITION-MATRIX.md)使用同一发行源码中的 Agent/Worker，新增远端能力仍需检查。

## 云端与生产环境

已有真实 Cloudflare 测试链路的认证、策略及 Tunnel 断连联调记录；本次仅补充文档和隔离救援验证，**没有重新部署或重测云端**。Worker 项目版本 `0.2.0` 不能唯一标识一次云端部署；缺少部署 ID 与完整运行记录的组合不在这里新增“通过”结论。

本页没有把个人生产设备的使用反馈列为所有配置的正式验收。实际部署仍需单设备试用，核对物理接口、双向流量路径、硬件卸载和开机阶段；开机验收应重启**运行 Proxy Guard 的路由器**，具体步骤见[安装与使用](USAGE.md)。异常恢复见[救援指南](RECOVERY.md)。
