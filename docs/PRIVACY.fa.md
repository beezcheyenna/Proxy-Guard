## درخواست‌های افزونه

بررسی پیش‌فرض اتصال و تطبیق اختیاری نشانی خروجی از طریق SOCKS محلی به نشانی رسمی HTTPS می‌روند. گردانندهٔ سرویس نشانی خروجی پروکسی، زمان و مسیر درخواست را می‌بیند. دکمهٔ «اجرای عیب‌یابی کامل» از طریق SOCKS محلی به `/f` درخواست می‌فرستد. در صورت انتخاب `/f`، تازه‌سازی مجاز API هم از آن استفاده می‌کند. پاسخ ممکن است نشانی خروجی، مکان تقریبی و اطلاعات عیب‌یابی شبکه را داشته باشد.

سرویس شخص ثالثِ انتخاب‌شده برای بررسی اتصال یا IPv4 خروجی نیز مبدأ و زمان درخواست را می‌بیند.

آزمون اختیاری UDP DNS فقط با فعال‌بودن گزینه‌ها و برقرار بودن شرایط مربوط اجرا می‌شوند. نام تنظیم‌شدهٔ پرس‌وجوی DNS برای مقصد ارسال می‌شود. فاصلهٔ بررسی‌ها، دورهٔ انتظار، پایش حساس و مدت درخواست‌ها بر تعداد درخواست‌ها اثر می‌گذارند. دسترس‌پذیری همیشگی یا نبود محدودیت نرخ برای هیچ سرویس ثالثی تضمین نمی‌شود.

پایش فرایندها، سوکت‌ها، رابط‌ها و گزارش کلاینت اطلاعات محلی را می‌خواند. افزونه این داده‌ها را به نگهدارندهٔ پروژه ارسال نمی‌کند.

## اطلاعات ذخیره‌شده

افزونه تنظیمات UCI، وضعیت تأیید و بازگردانی، وضعیت اجرا، رویدادها و گزارش بررسی‌ها را ذخیره می‌کند. گزارش‌های اجرا معمولاً در RAM هستند و با راه‌اندازی مجدد از بین می‌روند؛ اما ثبت پایدار یا راه دور گزارش سیستم که جداگانه تنظیم شده باشد ممکن است آن‌ها را نگه دارد یا ارسال کند.

UUID رابط API در حافظهٔ زمان اجرا نگه‌داری می‌شود. با راه‌اندازی دوبارهٔ روتر در حالی که API فعال است، UUID جدیدی ایجاد می‌شود. پاسخ‌های احرازشده و گزارش‌های قابل مشاهده برای مدیر افزونه شامل UUID هستند. عیب‌یابی کامل بیرونی از یک مقدار تصادفی جداگانه استفاده می‌کند.

## اشتراک گزارش و تصویر

اشکال‌های عادی را پس از حذف اطلاعات حساس در Issue عمومی ثبت کنید. جزئیات آسیب‌پذیری‌های رفع‌نشده را منتشر نکنید. [سیاست امنیتی](SECURITY.fa.md)

پیش از اشتراک، IP، دامنه، نام حساب، شناسهٔ دستگاه، توکن، احراز هویت SOCKS، نشانی پنل و اشتراک، پارامتر URL، Cookie، سرآیند Authorization، فایل HAR و کلید خصوصی را بررسی کنید. برای نمونهٔ شبکه می‌توان از `192.0.2.0/24`، `198.51.100.0/24`، `203.0.113.0/24` و `2001:db8::/32` استفاده کرد.

تصاویر README رابط واقعی را با نام کلاینت، نشانی‌ها، زمان و مصرف منابعِ نمونه نشان می‌دهند. این تصاویر برای معرفی رابط هستند و اندازه‌گیری محیط کاربر یا مدرکی برای سازگاری کلاینت محسوب نمی‌شوند. برای محدودهٔ پشتیبانی، [یادداشت‌های سازگاری](COMPATIBILITY.fa.md) را ببینید. نشانی جای‌نگهدار را وارد تنظیمات عملیاتی نکنید.

## نگهداری تنظیمات و کلیدها

تنظیمات واقعی، کلید دستگاه، کلید خصوصی گواهی و پشتیبان گزارش‌ها را بیرون از مخزن عمومی و در محل با دسترسی محدود نگه دارید. اعتبارنامهٔ آزمایشی و مقدار نمونه برای استقرار مناسب نیستند. اعلان‌های حق نشر اشخاص ثالث را حفظ کنید؛ نام عمومی پدیدآورنده، راز کاربر محسوب نمی‌شود.

پیش از انتشار، هم فایل‌های جدید و هم تاریخچهٔ Git را بررسی کنید. در صورت افشای اعتبارنامه، ابتدا آن را باطل یا تعویض کنید و سپس محتوای افشاشده و تاریخچهٔ مربوط را پاک کنید.
