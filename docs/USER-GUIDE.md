<a id="guide-setup"></a>

在使用 LuCI 和 firewall4/nftables 的路由器上安装 Proxy Guard。安装包格式须与固件的包管理器匹配。

## 首次设置

**停止 Proxy Guard 服务后，防火墙规则可能仍在阻断。** 需要解除阻断时，请明确关闭保护或按[故障救援步骤](RECOVERY.md)操作。

**「测试当前代理」通过仅说明本次探测成功。** 定时保护、API 限时断网或另一路检测故障仍可能阻断外网。

打开「服务 → 代理连接保护」。通过引导核对入口设备、IPv4 和 IPv6 范围、局域网例外及 SOCKS 端口。先使用「仅监测」，保存并应用后系统自检，通过后有 30 秒确认。自检失败或未确认时会回退配置。

若规则待核验，「确认保留此配置」暂不可用，原倒计时继续。超时后路由器会自动恢复之前的配置，即使网页已经关闭。

<a id="guide-requirements"></a>

## 系统要求与保护范围

使用 LuCI、firewall4 和 nftables。OpenWrt 24 使用 IPK，OpenWrt 25.12 使用 APK。iStoreOS 和 ImmortalWrt 按各自固件的包管理器及内核依赖选择。

<a id="guide-scope"></a>

保护覆盖实际经过路由器的流量。扩大范围前先用一台设备核对入口、IPv4 和 IPv6 路径、DNS 和管理访问。同网段旁路由的回程可能绕开本机。

## 工作模式

- **仅监测**记录故障，保留外网访问。
- **保护**在确认故障后阻断所选范围的外网流量。需要在路由器启动期间先阻断时，选择开机保护预设。
- **定时保护**支持每天或指定星期，采用固定 UTC 偏移，默认 UTC+00:00。

服务与日志监测可识别代理客户端重启并启动恢复检查。进程守护监测 Proxy Guard 自身。需要独立确认 UDP 通路时，可另行启用 UDP 代理通路检测。

<a id="advanced-settings"></a>

## 测试当前代理

| 设置 | 决定什么 |
| --- | --- |
| 连通性检测方式 | 默认走固定的官方 HTTPS 心跳，也可改用配置的第三方 HTTPS 目标。两种方式都经本机 SOCKS。 |
| 出口 IPv4 校验及来源 | 默认关闭。启用后默认读取官方 PGHB 返回的地址，即使连通性检测选的是第三方。选用第三方 IP 查询时，主地址超时才请求备用地址。 |
| 详细诊断 | LuCI 按需请求 PGHB `/f`。内网 API 的诊断接口默认请求 PGHB `/`，可设置为 `/f`。 |

在 LuCI 点击「测试当前代理」，可以用尚未保存的表单参数通过 SOCKS 检测，查看连通性、耗时和取得的出口 IPv4。保护设置在点「保存并应用」后生效。

设置表单下方的「配置与诊断」可检查配置和运行环境、测试当前代理、查看脱敏报告。这里也可以重新运行设置引导、编辑原始 UCI、载入上次确认的配置或恢复默认后重新设置。

在「配置与诊断」打开「测试当前代理」，再点弹窗中的「运行详细诊断」。路由器使用已应用的代理设置，经本机 SOCKS 请求一次 `/f`，并显示响应中的 `X-PGHB-*` 标头。 [PGHB 心跳与诊断说明](PGHB.md)

<a id="guide-options"></a>

## 检测和恢复参数

| 参数 | 官方 HTTPS | 第三方 HTTPS | 作用与调整代价 |
| --- | --- | --- | --- |
| 检测间隔 | 3 秒 | 10 秒 | 一次请求或一轮检测结束后的等待时间。间隔越短，请求越频繁。 |
| 请求超时 | 2 秒 | 每个目标 4 秒 | 延长超时能容忍较慢的响应，也可能推迟判定。 |
| 连续失败次数 | 2 次 | 3 轮 | 次数越多，触发阻断前可容忍更多短暂失败。 |
| 连续成功次数 | 2 次 | 2 轮 | 次数越多，恢复联网前需要更多成功结果。 |
| 敏感检测间隔 | 1 秒 | 1 秒 | 启用客户端监测后，在敏感检测和观察期间使用。 |

第三方 HTTPS 常规每轮默认至少需要一个目标成功。敏感检测期间要求配置的目标全部通过。

检测间隔、超时和连续失败次数共同决定故障确认速度。提高容错可以减少短暂波动造成的误阻断，也可能延后部分故障的确认。

启用客户端监测后，所选服务中断或日志中出现可识别的中断事件，均可触发阻断。满足配置的条件后开始恢复检查。恢复联网后，可在增强监测期间缩短间隔。期间再次失败可以重新阻断。

定时阻断需要启用总开关和保护模式。定时规则、API 请求和检测故障同时生效时，需要等所有阻断原因解除才会恢复。

## 阻断与恢复

主页显示连续失败次数和当前生效的阻断原因。一次失败尚未达到阈值时仍可能放行。定时保护、API 限时断网和代理检测故障可以同时存在。

内网 API 默认关闭。启用后使用 LuCI 页面显示的 UUID 调用。[内网 API 请求方法](USAGE.md#local-api)

在「事件日志」下可展开最近的连接检测明细和恢复记录。「清空日志和恢复记录」会一并清除这三类记录，当前恢复状态仍可查看，事件日志会新增一条清空操作记录。
