## 1.0.0-7 / 1.0.0-r7 の統合検証

以下は x86_64 で Proxy Guard `1.0.0-7`（IPK）または `1.0.0-r7`（APK）を検証した結果です。隔離した仮想マシンで実際の LuCI、SOCKS、TLS、nftables を使い、HTTPS にはテスト用のローカルサービスを用いました。

検証日は 2026-11-14（UTC+08:00）です。

| OpenWrt 25.12.6 (r33311-981c978eff) | 6.12.112 | APK のインストール、設定保持、再起動、削除。HTTPS と出口 IPv4、TLS フォールバック、LAN API、一時遮断とスケジュール遮断、実際の IPv4/IPv6 TCP/UDP 通信の遮断と復旧。 | 合格 |

検証結果は表に記載された構成と通信経路に適用されます。他のファームウェア、アーキテクチャ、転送モードは導入先のルーターで確認してください。

### 上書き更新と再インストールの確認

- **IPK `1.0.0-6` → `1.0.0-7`。** LuCI の試験環境で新しいパッケージをインストールしました。opkg は変更済みの `/etc/config/proxy_guard` を保持し、新しい既定の設定を `/etc/config/proxy_guard-opkg` に保存しました。
- **APK `1.0.0-r7` → `1.0.0-r7`。** OpenWrt 25.12.6 の試験環境で同じリビジョンを再インストールし、更新フックとインストールされたファイルを確認しました。

公開済みの 0.3 パッケージから 1.0 への上書き更新と、1.0 から 0.3 へのダウングレードは、移行手順として未検証です。 [移行ガイド](USAGE.ja.md#from-0-3)
