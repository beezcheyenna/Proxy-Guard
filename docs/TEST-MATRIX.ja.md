## 結果の読み方

- **モック・単体テスト**は時刻、インターフェース、システムコールを置き換え、解析と状態遷移を検証します。
- **隔離 VM の結合テスト**はゲストのカーネル、init、パッケージ管理、実プロキシを使い、管理された相手との通信を検証します。合格は記載した項目に限ります。
- **実配備の受け入れ**では物理機器、NIC、スイッチ、回線、非対称経路、長時間負荷を確認します。
- **クラウド連携**では実際の Worker/Tunnel の認証と制御を確認します。データ経路とコールドスタートは別に検証します。

日付は UTC、過去の Linux の日付は結果の保存日です。インストール、プロセスの起動、画面の表示だけでは機能の合格としません。

## クラウドと実配備

以前の実 Cloudflare 試験は認証、ポリシー、Tunnel 切断を確認しました。復旧の追加試験は隔離環境です。クラウドで合格を記録するには、配備のリビジョンと実行記録を残します。Worker の npm 版だけでは配備は特定できません。実機で端末 1 台から双方向経路、オフロード、起動を確認します。起動時保護は Proxy Guard が動くルーターを再起動します。[インストールと利用](USAGE.ja.md) を参照してください。
