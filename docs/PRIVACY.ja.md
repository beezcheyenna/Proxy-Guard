## プラグインが行う通信

既定の接続検査と任意の出口照合はローカル SOCKS 経由で公式 HTTPS に接続します。接続先の運営者はプロキシの出口アドレス、要求時刻、パスを確認できます。「詳細診断を実行」を選ぶとローカル SOCKS 経由で `/f` に接続します。設定で選択すると、権限のある API 呼び出しによる更新も `/f` を使用します。応答には出口アドレス、おおよその地域、ネットワークの診断情報が含まれることがあります。

外部サイトの接続確認や出口 IPv4 の取得を選ぶと、そのサービスにも接続元と時刻が伝わります。

オプションの UDP DNS 検査では、設定した問い合わせ名が接続先に伝わります。通信頻度は、検査間隔、待機時間、強化監視、リクエスト所要時間によって変わります。第三者のサービスについて、常時利用可能またはレート制限なしとは保証しません。

プロセス、ソケット、インターフェース、クライアントログの監視は本機内の情報を読み取ります。この情報をプロジェクトの保守者へ送信する機能ではありません。

## 保存される情報

プラグインは、UCI 設定、確認とロールバックの状態、実行状態、イベント、検査ログを保存します。実行ログは通常 RAM に置かれ、再起動で消えます。ただし、別途設定した永続化ログやリモート syslog は、保存や外部送信を行う場合があります。

API UUID は実行時のメモリに保持されます。API が有効な状態でルーターを再起動すると、UUID が再生成されます。認証済みの応答と、プラグイン管理者向けのイベントログに UUID が含まれます。外部への詳細診断には別の乱数を使います。

## 報告とスクリーンショットの共有

脆弱性はセキュリティ方針に従い非公開で報告してください。一般的な不具合は機密情報を除いて報告できます。

IP、ドメイン、アカウント名、デバイス ID、トークン、SOCKS 認証、管理パネルやサブスクリプションの URL、URL パラメーター、Cookie、Authorization ヘッダー、HAR、秘密鍵を確認してください。構成例には `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`、`2001:db8::/32` を使えます。

README の画像は実際の画面を使用していますが、クライアント名、アドレス、時刻、リソース使用量は表示用の例です。利用者の環境の測定結果や、クライアントの互換性を検証した証拠ではありません。対応範囲は[互換性の説明](COMPATIBILITY.ja.md)を確認してください。画像の仮アドレスを実際の設定に転記しないでください。

## 設定と鍵の保管

実際の設定、デバイス鍵、証明書の秘密鍵、ログのバックアップは、公開リポジトリの外でアクセスを制限して保管してください。テスト用認証情報と例の値は導入に使えません。第三者の著作権表示は保持してください。公開されている著作者情報は利用者の秘密情報ではありません。

共有前に、新規ファイルだけでなく Git 履歴も確認してください。認証情報が漏れた場合は、まず失効または再発行し、その後に公開内容と履歴を除去してください。
