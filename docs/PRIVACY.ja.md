## プラグインが行う通信

通常版は、設定された HTTPS 接続確認先へローカル SOCKS 経由でアクセスします。接続先の運営者は、プロキシの出口アドレス、リクエスト時刻、要求された URL を確認できます。新規インストールでは出口 IPv4 の一致確認は無効です。有効にすると設定された主アドレス取得先に問い合わせ、タイムアウトした場合だけ、同じ SOCKS 経路で予備の取得先を一度試します。次の検査は再び主取得先から始まります。主取得先が ipify で予備欄が空の場合は `https://4.ident.me/` を使用し、その他のホストには暗黙の予備先を設定しません。

任意の Cloudflare イベント検証と UDP DNS 検査は、それぞれの設定と前提条件を満たす場合に実行します。DNS 検査では、設定した問い合わせ名が接続先に伝わります。通信頻度は、検査間隔、待機時間、強化監視、リクエスト所要時間によって変わります。第三者のサービスについて、常時利用可能またはレート制限なしとは保証しません。

プロセス、ソケット、インターフェース、クライアントログの監視は本機内の情報を読み取ります。この情報をプロジェクトの保守者へ送信する機能ではありません。Pro は利用者が設定した制御先へ接続します。VPS、HTTPS 接続先、利用中の Cloudflare コンポーネントは、接続元アドレス、認証要求、関連する状態情報を扱います。制御経路とプロキシ経路のハートビートは別設定です。自宅 IP の認可情報は機密性のある運用データです。

VPS 出口の測定は既定で無効です。有効時は Agent が VPS の IPv4 既定経路から ipify に問い合わせます。運営者は送信元と時刻を確認できます。[出口 API](VPS-EGRESS-INFO.ja.md) を参照してください。

公開ソースと例には、利用可能なアカウント認証情報、個人の出口アドレス、稼働中の Worker/VPC リソース識別子を含めていません。導入者自身の値を設定してください。[Pro 構成](PRO-COMPANION.ja.md)も参照してください。

## 保存される情報

プラグインは、UCI 設定、確認とロールバックの状態、実行状態、イベント、検査ログを保存します。実行ログは通常 RAM に置かれ、再起動で消えます。ただし、別途設定した永続化ログやリモート syslog は、保存や外部送信を行う場合があります。

保存済みの秘密情報は root にアクセスを限定したファイルで管理します。生の UCI エクスポートは、既存の機密項目を維持マーカーで表し、秘密ファイル自体は出力しません。新たに入力した値、バックアップ、スクリーンショット、シェル履歴、エラーログから漏れる可能性は残ります。維持マーカーは認証情報のバックアップではありません。

VPS Agent は設定に従い、認可、ポリシー、保守操作の重複防止情報を保存します。任意の診断や信頼済みテレメトリーには訪問元アドレスが含まれる場合があります。Worker ログと Cloudflare の保持設定は、導入先アカウントで管理します。

## 設定と鍵の保管

実際の設定、デバイス鍵、Agent の非公開設定、証明書の秘密鍵、ログのバックアップは、公開リポジトリの外でアクセスを制限して保管してください。テスト用認証情報と例の値は導入に使えません。第三者の著作権表示は保持してください。公開されている著作者情報は利用者の秘密情報ではありません。

共有前に、新規ファイルだけでなく Git 履歴も確認してください。認証情報が漏れた場合は、まず失効または再発行し、その後に公開内容と履歴を除去してください。
