# 普通版与 Pro 的功能范围

普通版 `0.3.0-21` 与 Pro `0.3.1-5` 使用独立包和版本号。普通版提供路由器上的连接保护；Pro 增加所选 VPS 服务端口的访问管理。

| 范围 | 普通版 | Pro |
| --- | --- | --- |
| 部署位置 | OpenWrt 路由器 | 同一路由器扩展，加独立 Linux Agent；可选 Worker/Tunnel |
| 本地代理验证 | 经本机 SOCKS 的 HTTPS、可选出口 IPv4、可选 SOCKS5 UDP | 沿用普通版，可导入 VPS 出口候选 |
| 本地规则 | 明确入口、地址范围及例外；IPv4/IPv6，TCP/UDP | 沿用普通版 |
| 客户端适配 | PassWall、PassWall2、OpenClash、Nikki、HomeProxy；按具体版本和模式验证 | 沿用普通版 |
| 状态机 | 故障阈值、等待、增强监测、开机/定时保护 | 可选叠加远端健康条件及维护恢复 |
| 管理界面 | 状态、事件/检查日志、五种语言、引导、原始配置、自检与有限恢复 | 增加选定端口、认证连接、远端状态与固定操作 |
| 远端访问策略 | 无 | 每条端口规则独立选择白名单、标准防滥用或观察，支持阈值和来源配置 |
| SSH | 不管理 VPS SSH | 单独选择托管；双心跳失联后的持续或限时应急访问 |
| 远程维护 | 无 | 单独授权 VPS 重启或指定 Xray 内核操作（含受支持的 3x-ui 托管方式），不接受任意命令 |

## 独立升级

普通版与 Pro 的安装包独立编号，通过最低基础版本与 API 检查兼容。兼容时只升级 Pro 不要求重装基础包。基础层自身的安全、状态机或固件兼容修复仍需更新基础包。Pro 的专属界面和五种语言目录随 Pro 包更新；普通版本身的修复与功能变化仍需升级普通版。

Worker 与 Linux Agent 使用自己的协议/能力检查。新增远端能力可能需要更新对应配套，不能只靠路由器扩展获得服务器端实现。Worker 的 npm 项目版本不等同于 Pro 安装包版本。

Pro 自带五种语言的专属页面、策略确认和原始配置编辑器。新版 Pro 可以安装在兼容的旧普通版上。若先升级普通版，安装钩子会从设备上的旧普通版词库保留旧 Pro 仍使用的词条。安装新版 Pro 后会清理这份临时兼容词库。

## 当前边界

- 新装本地保护与 Pro 总开关默认关闭；SSH 托管、维护等另行选择。
- 监听发现只推荐候选端口，未选择端口沿用系统防火墙，不做整机默认拒绝。
- 默认控制通信及家庭地址同步配置采用 IPv4；IPv6 数据面保护不等同于 IPv6 云端管理链路已验收。
- 当前以一组路由器身份与 Agent 为中心，不承诺多 VPS 统一管理、自动密钥轮换或任意客户端兼容。
- 可信结构化遥测缺失时，不推断回落连接身份或执行精确回落带宽分类。
- 运行进程、监听端口和“运行完成”日志不能替代真实代理请求验证。

已进行安装、界面、故障恢复和兼容测试。支持条件与已知限制见[兼容范围](COMPATIBILITY.md)。
