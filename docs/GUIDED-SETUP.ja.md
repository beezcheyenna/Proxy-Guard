## 設定ウィザード

LuCI の「サービス → プロキシ接続保護」を開き、ウィザードを開始します。

1. **LAN の入口デバイス。** 対象端末の通信が実際に入る LAN インターフェースを選びます。複数の物理ポートをブリッジしている場合は、`br-lan` など実際に使われるデバイスを確認します。
2. **保護プリセット。** 監視のみ、障害時の保護、起動時と障害時の保護から選びます。自動検出でクライアントを一つに絞れない場合は手動で選びます。
3. **保護範囲と例外。** IPv4 の送信元範囲と IPv6 の保護範囲を確認し、IPv6 保護を有効にするか決めます。LAN の例外と DNS・プロキシのポートを実際の構成に合わせます。
4. **設定内容の確認。** SOCKS の待受、保護範囲、例外を確認します。適用後に検証が通ったら、ダイアログで確定します。遮断を有効にする準備ができるまでは監視のみを使用できます。

「設定と診断」からウィザードを再実行できます。前回確定した設定を読み込んだり、初期値を読み込んで確認したりすることもできます。

「サービス → プロキシ接続保護」でウィザードを開き、入口インターフェース、IPv4 と IPv6 の範囲、ローカル例外、SOCKS ポートを確認します。最初は監視専用で試します。保存して適用すると自己検査が実行され、確認時間は 30 秒です。検査に失敗した場合や確認しなかった場合は元の設定に戻ります。

保護の対象は実際にルーターを経由する通信です。範囲を広げる前に一台で入口、IPv4 と IPv6、DNS、管理経路を確認します。同一サブネットでは戻りの通信がルーターを迂回する場合があります。
