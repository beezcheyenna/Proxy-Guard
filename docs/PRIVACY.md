## 联网行为

普通版按配置经本机 SOCKS 请求连通性目标；目标站点能看到代理出口地址和请求时间。新装出口 IPv4 一致性校验关闭，相关 IP 获取地址仅在启用条件满足时请求。启用出口 IPv4 校验后，只有主地址超时才会通过同一个 SOCKS 代理查询备用地址。备用地址可自填，使用 ipify 且备用留空时默认查询 `4.ident.me`。每轮检测先请求主地址；其他主域名在未填写备用地址时，不会隐式切换。出口校验服务能看到代理出口地址和请求时间。可选 CF 事件检查、UDP DNS 探测均按各自开关及关联条件执行；实际地址见配置，不能把任何第三方接口称为不限流或永久可用。

可选 UDP DNS 检查会向所配置的目标发送查询名称。

服务进程、监听端口、接口与运行日志监视是本机读取。它们不等于持续向维护者发送数据。频率还受到等待、增强监测、请求超时与普通轮询间隔影响，不承诺固定的公网请求总数。

Pro 使用用户自己配置的控制入口。Cloudflare、自己的 VPS 或直接 HTTPS 入口会接触相应的连接来源、认证请求和状态；控制链路与独立代理路径心跳分别配置。默认控制配置采用 IPv4，家庭授权地址属于敏感运营数据。

本源码没有预填可用的账户、Worker/VPC 资源 ID 或个人出口地址。示例中的服务名与占位符必须由部署者自行替换。详见[Pro 配套](PRO-COMPANION.md)。

## 本地信息

本插件会保存自己的 UCI 设置、确认回退状态、运行状态、事件与检查日志。运行日志通常存放于 RAM，系统另行配置的持久化/远程 syslog 仍可能写入磁盘或外发。

已有凭据保存在 root 限定文件中；原始 UCI 导出用保留标记处理已保存敏感字段，不导出实际密钥文件。管理员主动填写的新值、备份、截图、命令行历史或错误日志仍可能泄露凭据。

VPS Agent 的授权、策略和维护去重信息按对应配置保存。可选诊断、可信日志和遥测源可能含来源地址；不应直接分享原文件。Worker 的服务日志及 Cloudflare 平台保留策略由部署账号自行控制。

## 分享问题报告

涉及本项目或 VPS 部署的安全问题，请先按照[安全反馈政策](SECURITY.md)私下发送至 [beezcheyenna268@gmail.com](mailto:beezcheyenna268@gmail.com)。普通功能问题才使用脱敏的公开报告；即使通过邮件，也不要发送仍有效的凭据。

仅提供足够复现问题的最少脱敏片段。检查 IP、域名、账号、device_id、token、SOCKS 认证、面板/订阅地址、URL 参数、Cookie、Authorization、HAR 及私钥。

使用文档地址描述拓扑，例如 192.0.2.0/24、198.51.100.0/24、203.0.113.0/24、2001:db8::/32。回环、全零、链路本地、多播及明确标注的局域网分类/拒绝测试地址也会出现在源码中；它们不是自动发现的用户网络。

测试中的固定伪凭据与文档占位符不能用于部署。保留上游版权声明中的公开作者信息，不将其当成用户凭据删除。

README 截图取自真实界面，客户端名称、地址、时间和资源用量使用展示示例值，不代表用户环境的实测结果，也不作为客户端兼容性验证依据。支持范围见[兼容说明](COMPATIBILITY.md)。不要将截图中的占位地址直接填入实际配置。

## 保管配置与密钥

请将真实配置、设备密钥、Agent 私有配置、证书私钥和日志备份保存在访问受限的位置，不要提交到公开仓库。示例文件中的占位值不能用于部署；原始 UCI 导出的保留标记也不等于密钥备份。

提交 Issue、Pull Request 或示例配置前，检查新增内容及 Git 历史中的地址、凭据和订阅信息。若发现凭据泄露，应先撤销或轮换，再清理公开内容和历史。
