## 联网行为

默认连通性检测和可选的官方出口校验经本机 SOCKS 请求项目 HTTPS 接口。接口运营方可看到代理出口地址、请求时间和路径。点「运行详细诊断」时，路由器通过本机 SOCKS 请求 `/f`。经授权的 API 主动刷新也可按设置使用 `/f`。响应可能包含出口地址、近似地理位置和网络诊断数据。

如果选用第三方连通性或出口 IPv4 检测，所选服务同样可见请求的来源地址和时间。

可选 UDP DNS 检查会向所配置的目标发送查询名称。

服务进程、监听端口、接口与运行日志监视是本机读取。它们不等于持续向维护者发送数据。频率还受到等待、增强监测、请求超时与普通轮询间隔影响，不承诺固定的公网请求总数。

## 本地信息

本插件会保存自己的 UCI 设置、确认回退状态、运行状态、事件与检查日志。运行日志通常存放于 RAM，系统另行配置的持久化/远程 syslog 仍可能写入磁盘或外发。

API UUID 存在运行内存中。接口启用时，路由器重启会重新生成 UUID。已认证的 API 响应和插件管理员可见的事件日志包含 UUID。对外发起的详细心跳诊断使用单独生成的随机数。

## 分享问题报告

普通问题可在脱敏后公开反馈。请勿公开未修复的漏洞细节。

仅提供足够复现问题的最少脱敏片段。检查 IP、域名、账号、device_id、token、SOCKS 认证、面板/订阅地址、URL 参数、Cookie、Authorization、HAR 及私钥。

使用文档地址描述拓扑，例如 192.0.2.0/24、198.51.100.0/24、203.0.113.0/24、2001:db8::/32。回环、全零、链路本地、多播及明确标注的局域网分类/拒绝测试地址也会出现在源码中；它们不是自动发现的用户网络。

测试中的固定伪凭据与文档占位符不能用于部署。保留上游版权声明中的公开作者信息，不将其当成用户凭据删除。

README 截图取自真实界面，客户端名称、地址、时间、资源用量和日志均使用示例，不代表用户环境的实测结果，也不作为客户端兼容性验证依据。支持范围见[兼容说明](COMPATIBILITY.md)。不要将截图中的占位地址直接填入实际配置。

## 保管配置与密钥

请将真实配置、设备密钥、证书私钥和日志备份保存在访问受限的位置，不要提交到公开仓库。示例文件中的占位值不能用于部署；原始 UCI 导出的保留标记也不等于密钥备份。

提交 Issue、Pull Request 或示例配置前，检查新增内容及 Git 历史中的地址、凭据和订阅信息。若发现凭据泄露，应先撤销或轮换，再清理公开内容和历史。
