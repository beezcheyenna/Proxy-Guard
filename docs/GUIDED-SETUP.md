# 设置引导与确认回退

[English](GUIDED-SETUP.en.md) · [简体中文](GUIDED-SETUP.md) · [日本語](GUIDED-SETUP.ja.md) · [Русский](GUIDED-SETUP.ru.md) · [فارسی](GUIDED-SETUP.fa.md)

首次打开新装插件页面时显示引导。关闭引导或选择“稍后设置”会保留关闭状态；重新进入设置页可再次运行。

1. 选择现有 LAN 三层入口设备。推荐项来自本机 netifd 地址与 LAN 防火墙区域；已在 LAN 上启用地址伪装也可以识别，不会修改现有 NAT。
2. 选择仅监测、故障保护或开机保护预设，核对客户端、SOCKS 端口、服务监视及定时选项。更改控件不会启动服务。
3. 核对源地址范围、局域网例外、代理入口与 DNS 重定向端口。自动发现只是一份草稿；跨网段局域网或特殊端口需补充。
4. 查看摘要并点击“保存并应用”。退出、返回或恢复默认预设都不会提前应用。

IPv6 必须单独选择并确认：使用发现的前缀、手填范围、所选入口全部来源（`::/0`），或明确不匹配 IPv6。发现的前缀未必覆盖隐私地址和后续前缀变化，应按拓扑核对。选择不保护 IPv6 会保存独立的 `ipv6_protect=0`，避免空列表被 UCI 省略后重新扩大范围；此选择不关闭系统 IPv6。自动发现的 LAN IPv6 前缀加入局域网例外。不要把全部公网地址加入例外，也不要把未知上游口当成 LAN。

## 预设如何选择

| 预设 | 适合的阶段 | 应核对 |
| --- | --- | --- |
| 仅监测 | 第一次识别设备与代理客户端，检查检测结果 | 不阻断外网；成功并不代表真实阻断路径已经验收。 |
| 故障保护 | 已明确入口、范围和例外，需要故障时断外网 | 客户端、SOCKS 与已启用监视项目正确，保留管理路径。 |
| 开机保护 | 已验收常规故障保护，需要启动阶段先限制外网 | 保护总开关、保护模式、服务监视及开机保护均开启，再单独做重启验收。 |

自动推荐不代表已识别完整拓扑。多个 LAN、跨网段服务、IPv6 动态前缀、VPN 和容器应逐项核对。引导不会新建网口、修改网关/NAT、重写 DNS 或替用户配置代理分流。若所选设备只有交换功能且流量使用其他网关，应先确认它是否真是保护路径。

定时不随预设自动生成。需要每天或每周保护时，自行启用定时、填写不同的开始/结束时间、重复星期与 UTC 偏移，再核对摘要。恢复默认预设不会替你提交配置，也不等于把系统恢复出厂。

## 什么会触发回退

后端在提交前验证配置与内核能力，随后核对检测进程与实际规则。自检最多等待约 120 秒；通过后开始 30 秒确认倒计时。只有当前应用会话能确认或取消。另一会话无法读取确认令牌，也不能覆盖进行中的启用事务。

倒计时由路由器维护，浏览器刷新、关闭、网络断开或系统日期或时间改变不会延长它。确认前重启会回退；后端检测到损坏的事务状态时使用独立备份尝试恢复。若实际规则尚未恢复，不能把配置文件已恢复显示成回退成功。

代理本身不可用时，保护模式应阻断并等待恢复。这不属于应自动关闭保护的自检失败。首次启用因配置或规则错误失败时保持关闭；已有确认过的保护则恢复原有配置。明确关闭优先于待确认的启用，不能让旧任务重新启用。

“载入上次确认的设置”和“恢复默认并重新设置”只填写表单，仍需应用。引导返回上一步会保留已选择内容；“重置”清除尚未保存的表单及引导草稿。升级保留原有配置，不强制重走首次引导。

## Pro 预期出口地址

先保存 Pro 的认证连接，再到基本设置启用出口校验、选择来源并读取 VPS 地址。支持公网接口、面板配置中的地址提示和可选的默认路由测量。多个候选需要手动选择；没有匹配来源时可手填。

面板来源读取 Agent 中明确配置的可信本地 Xray 配置路径，不会把 REALITY 目标或远端上游服务器当成自己的出口，也不会读取并输出私钥。并不承诺适配所有面板 API 或多跳出站。测量默认关闭；启用后有固定目标、超时与最短间隔，读取状态不会无限增加外网请求。

导入是一次草稿操作。VPS 位于 NAT 后、使用 WARP、多个出口或多级代理时，接口和面板地址可能不等于真实出口；应按实际出站配置选择，并保留独立 SOCKS 校验。不能自动把当前检测到的未知 IP 学成可信预期地址。

## 应自行核对的路径

确认从一台受保护设备发出的 IPv4/IPv6、TCP/UDP 新连接和已有连接确实经过本机；测试故障时外网被阻断，局域网、DNS、管理和路由器本机仍可用。再测试一个使用其他网关的设备未受影响。

没有经过插件所在设备的回程或交换流量无法被它拦截。自检通过只说明本机配置、进程和规则达到所检验条件，不等于完整浏览器、物理加速或生产拓扑验收。

## Pro 的远端策略确认

Pro 的“保存并应用”默认请求 VPS Agent 以临时策略试运行，VPS 规则应用完成后开始确认计时，默认60秒，可在30–300秒之间设置。确认按钮只属于发起应用的登录会话。关闭网页不延长计时；未确认时由 VPS 恢复先前端口及 SSH 策略，保留递增的版本号与当前认证 IP，不恢复过期授权。进程重启沿用剩余时间，VPS 开机发现未确认策略会先恢复。Agent 的检查循环通常每5秒处理一次到期；Agent 完全无法运行时仍需服务守护恢复，不能承诺任意内核或存储故障下立即回退。

路由器会保留受限权限的私有配置快照，直到结果明确。确认已发出但回复丢失时显示“结果未知”，重查远端，避免一端确认、一端盲目恢复。其他会话修改过配置或密钥时不覆盖新修改，而是报告冲突。使用新的远端能力需要匹配的 Agent；经 Cloudflare 控制时，还需要匹配的 Worker。旧登录会话缺少新权限时应重新登录后应用。关闭“策略确认”或直接使用旧版/root命令行同步接口会立即应用，应自行保留独立管理入口。

“停止同步”停止心跳和新同步，不代表 VPS 立即删除已有端口规则。要移除本插件规则，先点“准备移除 VPS 规则”，审核草稿，保存并应用并确认远端已停用本插件的代理端口规则及 SSH 托管，再停止同步。此操作不会关闭代理或 SSH 服务本身。VPS 原系统防火墙仍然生效，不保证移除本插件规则后公网就能访问。

应用或回退中断后，应重新打开状态区核对结果。若显示“结果未知”或配置冲突，请先重查远端，并保留独立管理入口。停止同步不代表远端规则已经移除。
