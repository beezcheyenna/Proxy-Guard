## 设置引导

在 LuCI 打开「服务 → 代理连接保护」，启动设置引导。

1. **局域网入口设备。** 选择受保护设备实际经过的 LAN 接口。多个物理口组成网桥时，核对实际入口，例如 `br-lan`。
2. **保护预设。** 选择仅监测、故障时阻断，或开机和故障时都阻断。如果自动识别无法确定唯一的代理客户端，手动选择。
3. **保护范围和例外。** 核对源 IPv4 范围及 IPv6 范围，确认是否启用 IPv6 保护。按实际配置检查局域网例外、DNS 端口和代理端口。
4. **核对设置。** 确认 SOCKS 监听、保护范围和例外。应用后等自检通过，再在弹窗中确认。准备好启用阻断之前，可以使用仅监测。

可在「配置与诊断」重新运行引导，也可载入上次确认的配置或恢复默认值供核对。

打开「服务 → 代理连接保护」。通过引导核对入口设备、IPv4 和 IPv6 范围、局域网例外及 SOCKS 端口。先使用「仅监测」，保存并应用后系统自检，通过后有 30 秒确认。自检失败或未确认时会回退配置。

保护覆盖实际经过路由器的流量。扩大范围前先用一台设备核对入口、IPv4 和 IPv6 路径、DNS 和管理访问。同网段旁路由的回程可能绕开本机。
