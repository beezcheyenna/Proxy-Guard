# Сообщение об уязвимостях

[English](SECURITY.en.md) · [简体中文](SECURITY.md) · [日本語](SECURITY.ja.md) · [Русский](SECURITY.ru.md) · [فارسی](SECURITY.fa.md)

Проект пока не публикует канал для конфиденциальных сообщений об уязвимостях. Открытые формы Issue предназначены для обычных ошибок и замечаний к документации. В публичных сообщениях не приводите подробности неисправленных уязвимостей, учётные данные и адреса рабочих систем.
